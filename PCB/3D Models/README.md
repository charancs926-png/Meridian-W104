# Switch model attribution

Original model: SW_Cherry_MX_PCB.stp from [keyswitch-kicad-library](https://github.com/edmondhuang/keyswitch-kicad-library), main branch.
License: CC BY-SA; included in LICENSE-CC-BY-SA. The original file is retained.

MX PCB Switch.step is the same geometry translated (-2.54, -5.08, 0) mm to match the pin-1 origin of KiCad's stock MX footprints. The same model is used for all key widths because the switch body is unchanged. Vertical numpad switches follow their footprint rotation.

The board links all 104 switches with ${KIPRJMOD}, so no extra model installation is needed. Purchased switch appearance can differ from this Cherry-compatible reference model.
